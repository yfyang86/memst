#### Error Handling Migration Plan

**Current State:**
```rust
// kg_extract - uses anyhow
pub async fn extract_from_text(&self, text: &str) -> anyhow::Result<KgExtractionResult>

// kg_evolve - uses Result<bool, String>
pub fn apply_action(&self, ...) -> Result<bool, String>

// kg_decay - uses Result<(), Error> (from memst_core)
pub fn apply_decay(&self, graph: &mut KnowledgeGraph) -> Result<(), Error>
```

**Target State (Sprint 2):**
```rust
// All modules use standard error type
pub type Result<T> = std::result::Result<T, KgError>;

#[derive(Error, Debug)]
pub enum KgError {
    #[error("Entity not found: {0}")]
    EntityNotFound(EntityId),
    #[error("Graph operation failed: {0}")]
    GraphError(#[from] memst_core::error::Error),
    #[error("LLM error: {0}")]
    LlmError(String),
    #[error("Action not implemented: {0}")]
    NotImplemented(String),
}
```
